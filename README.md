## 🎼 怪兽交响团 —— 用 Git 组建你的怪兽乐团

一个用于**版本控制教学**的音乐小游戏：仓库每提交一个新版本，乐团里就会多一位小怪兽乐手。每只怪兽控制一种乐器，可以单独开关；当多位怪兽同时演奏，就会汇成交响乐 🎻

### 游戏玩法

1. 打开 `index.html`（或部署到 GitHub Pages 在线玩）
2. 点击小怪兽，开关它的乐器（休眠的怪兽会打瞌睡 💤）
3. 「全体开演」一键控制整个乐团
4. 多位怪兽同时开演，欣赏交响乐！

### 🎓 版本控制小课堂

这个仓库本身就是教材：每一次 commit 都对应游戏的一个版本。

```bash
git log --oneline   # 回顾乐团的成长历史
git tag             # 查看所有版本标签
git show v1.0.0     # 看看 v1.0.0 这一版改了什么
```

试着回答：贝斯手怪兽是在哪个版本加入乐团的？用 `git log` 找到答案吧！
