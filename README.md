# GitStudy-AngelBand

Support for Git teaching

## AngelBand —— 西部舞台上的乐团

一个用于**版本控制教学**的音乐小游戏：每提交一个新版本，舞台上就多一位乐手。每位乐手控制一条音轨，可以单独开关；几位同时开演，就凑成一支完整的乐队。

当前版本 **v2.2.0**，舞台上有两位乐手：

| 角色 | 位置 | 音轨 | 演出动作 |
| ---- | ---- | ---- | -------- |
| 唱片小车 | 台上左侧 | `singer.mp3` | `Special` 循环，车身随拍轻微呼吸、微摆 |
| 红发吉他手 | 台上右侧 | `guitar.mp3` | `Relax` 抱琴，叠加右手扫弦与四指拨弦 |

两位各自独立：点一下变彩色并开演，再点变灰退场；同时开演时音轨会自动对齐到同一时刻。底部进度条可以拖动跳转，跳转后拨弦相位会重新对拍。

## 怎么玩

1. 打开 `index.html`（或部署到 GitHub Pages 在线玩）
2. 点击台上的乐手，开关他/她的音轨
3. 拖动底部进度条跳到任意位置，或按播放键控制走带
4. 两位一起开演，听完整编曲

## 目录

```
index.html          主页面：西部舞台 + 乐手 + 播放条
spine-preview.html  角色调试页：单独看吉他手，切换全部 7 个动画
spine/              角色资源
  angel.*           吉他手（.skel / .atlas / .png）
  phonor.*          主唱唱片小车
  lib/              PixiJS、pixi-spine 3.8、两份打包后的资源数据
guitar.mp3          吉他音轨
singer.mp3          主唱音轨
```

角色是 Spine **3.8.99 二进制**格式，用 PixiJS v7 + pixi-spine 3.8 渲染。因为预览服务器不放行 `.skel` / `.atlas` 后缀，资源已打包成 `spine/lib/*-assets.js`（base64 内嵌），这样本地双击打开也不会被 CORS 拦住。

## 版本控制小课堂

这个仓库本身就是教材：每一次 commit 对应游戏的一个版本，每个 tag 都是一个能玩的完整版本。

```bash
git log --oneline          # 回顾乐团的成长历史
git tag                    # 查看所有版本标签
git show v1.0.0            # 看看第一版改了什么
git diff v2.1.0 v2.2.0     # 对比"加入主唱"这一版动了哪些文件
```

试着回答：主唱唱片小车是在哪一版加入的？它带了哪几个新文件？用 `git show` 找找看。
