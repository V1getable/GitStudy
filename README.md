# GitStudy-AngelBand

Support for Git teaching

## 🎸 AngelBand —— 西部舞台上的乐团

一个用于**版本控制教学**的音乐小游戏：每提交一个新版本，舞台上就多一位乐手。每位乐手控制一条音轨，可以单独开关；多位同时开演，就汇成完整合奏。

当前版本：**v2.1.0**，吉他手换成 Spine 骨骼角色（红发、牛仔帽、抱着吉他）。底动作是 `Relax` 抱琴姿态，再按 147.28 BPM 节拍叠加右手扫弦与四指依次拨动，形成弹吉他循环；未上场时呈灰色静止，上场后变彩并开始演奏。西部舞台可拖动进度条跳转，跳转后拨弦相位自动对时。

> 角色资源位于 `spine/`，用 PixiJS + pixi-spine 3.8 渲染（对应 Spine 3.8.99 二进制 `.skel`）。
> 单独看角色、切换 7 个动画可以打开 `spine-preview.html`。

### 🎓 版本控制小课堂

这个仓库本身就是教材：每一次 commit 都对应游戏的一个版本。

```bash
git log --oneline   # 回顾乐团的成长历史
git tag             # 查看所有版本标签
git show v1.0.0     # 看看 v1.0.0 这一版改了什么
```

试着回答：贝斯手怪兽是在哪个版本加入乐团的？用 `git log` 找到答案吧！
